# Folio

Folio는 영어 지문 사진을 읽어 문항 구조를 정리하고, 문장을 의미 단위로 나눈 뒤 직독직해를 보여 주는 웹 애플리케이션입니다. 전북대학교 영어영문학 수업용 분석실로 브라우저에서 바로 사용합니다.

사진을 올리면 한글과 영어를 함께 읽고, 질문·지문·어휘 주석·선지를 구분해 편집 칸에 넣습니다. 이어서 직독직해, 핵심 요약, 구문·어휘 해설, 변형 문제를 같은 화면에서 요청할 수 있습니다.

## 프로젝트 개요 및 기술 스택

브라우저가 지문 입력, OCR 후처리, 문장 경계 나누기, 청크 분할, 직독직해 렌더링을 담당합니다. Python 서버는 정적 파일을 제공하고, Gemini 호출만 같은 출처에서 중계합니다. API 키는 페이지 소스에 들어가지 않습니다.

| 영역 | 구성 |
| --- | --- |
| 화면 | HTML, Tailwind CSS, `styles.css` |
| 애플리케이션 | Vanilla JavaScript (`app.js`) |
| 글자 인식 | Tesseract.js 5.1.1, 한국어+영어 (`kor+eng`) |
| 로컬 서버 | Python 3 표준 라이브러리 `http.server` (`server.py`) |
| 언어 모델 | Gemini API (`gemini-3.8-flash`), `POST /api/gemini` |

별도 패키지 설치는 없습니다. Tailwind, 글꼴, Tesseract.js는 CDN에서 불러오므로 실행 중에는 인터넷 연결이 필요합니다.

OCR 결과는 문장 부호 정리, 선지 번호 정규화, 오인식 기호 제거, 어휘 주석(`*`, `**`, `***`) 복원을 거친 뒤 화면에 표시됩니다. 직독직해는 인용문·약어·화행 꼬리표를 한 문장으로 유지하고, 전치사와 to부정사 뒤에서 청크를 나눕니다. Gemini를 쓸 수 없으면 브라우저 안의 직독직해로 결과를 만듭니다.

## 사전 요구사항 및 설치 방법

- Python 3
- 최신 Chrome, Edge, Safari 중 하나
- 인터넷 연결 (CDN, Gemini)

저장소를 받은 폴더에서 아래 파일을 확인합니다.

```text
index.html    화면
styles.css    스타일
app.js        OCR, 청크 분할, 직독직해, 분석 요청
server.py     정적 파일 제공과 Gemini 중계
.env          Gemini API 키 (저장소에 포함하지 않음)
```

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급합니다.
2. 프로젝트 루트에 `.env` 파일을 만듭니다.
3. 아래처럼 키를 등호 오른쪽에 넣습니다. 따옴표는 붙이지 않습니다.

```env
GEMINI_API_KEY=
```

키 없이도 서버는 켜집니다. 이 경우 직독직해는 브라우저에서 만들고, Gemini가 필요한 분석은 예시 결과로 대체됩니다.

## 로컬 서버 실행 가이드

프로젝트 루트에서 서버를 실행합니다.

```bash
python3 server.py
```

터미널에 `Folio http://127.0.0.1:8000`이 보이면 준비된 것입니다. 브라우저에서 다음 주소로 엽니다.

```text
http://localhost:8000
```

`index.html`을 파일로 직접 열면 브라우저가 API 요청을 막습니다. 반드시 위 주소로 접속합니다.

포트를 바꾸려면 실행 전에 `PORT`를 지정합니다.

```bash
PORT=8080 python3 server.py
```

서버를 끝낼 때는 해당 터미널에서 `Ctrl+C`를 누릅니다.

## 보안 및 환경 변수 주의사항

- `.env`에는 `GEMINI_API_KEY`만 둡니다. 키를 소스 코드, README, 이슈, 채팅에 붙여 넣지 않습니다.
- `.env`는 Git에 커밋하지 않습니다. `git add` 전에 목록에 `.env`가 있는지 확인합니다.
- 서버는 `127.0.0.1`에만 바인딩합니다. 같은 컴퓨터의 브라우저에서만 접속합니다.
- `GET /.env`는 404를 반환합니다. 키 값은 `/api/gemini/status`에도 포함되지 않습니다.
- Gemini 요청은 서버가 `x-goog-api-key` 헤더로 보내며, 브라우저 페이지에는 키를 내려 주지 않습니다.
- 오류 메시지에 키가 섞이면 서버가 그 문자열을 지운 뒤 최대 300자만 반환합니다.
- 브라우저 설정에 따로 저장한 키가 있다면 그 값은 `localStorage`에 남습니다. 공용 컴퓨터에서는 사용 후 지웁니다.
- 키가 노출되면 Google AI Studio에서 해당 키를 폐기하고 새 키를 `.env`에만 다시 저장합니다.
